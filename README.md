# SBS

Приложение-подсказка для преподавателя: небольшое прозрачное окно поверх всех окон,
которое **не попадает в демонстрацию экрана** (флаг `contentProtected`, на Windows это
`WDA_EXCLUDEFROMCAPTURE`). Вопрос вводится в окно, ответ приходит от локальной модели через [Ollama](https://ollama.com).

Стек: Tauri 2 · Vue 3 · TypeScript · Vite.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+Alt+Пробел | показать окно и поставить курсор в поле ввода |
| Ctrl+Alt+H | скрыть / показать окно |
| Ctrl+Alt+C | сквозной режим: клики проходят через окно |
| Ctrl+Alt+Q | закрыть приложение (так же, как крестик) |

## Запуск (Windows)

Нужно один раз установить: [Node.js](https://nodejs.org), [Rust](https://rustup.rs),
Microsoft C++ Build Tools (рабочая нагрузка «Разработка классических приложений на C++»), WebView2 (есть в Windows 11).

```
npm install
npm run tauri dev
```

Сборка установщика: `npm run tauri build`.

## Модель

```
ollama pull qwen2.5:7b
```

Название модели меняется в поле внизу окна.

## Что проверить вручную

Скрытие окна работает на уровне Windows, но стоит убедиться на своих программах:
Zoom, Discord, Телемост, Google Meet — включить демонстрацию экрана и посмотреть, не видно ли окно в трансляции.
